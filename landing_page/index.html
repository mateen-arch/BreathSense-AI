Frequently Asked Questions

Does the app work if the Python backend server is offline?
Yes! BreathSense AI features an automatic dual-mode system. If the backend server is unreachable, the app automatically seamlessly switches to Standalone Local Mode, allowing continuous respiration monitoring, medication logging, and trend evaluation.
Is the X-ray screening intended for medical diagnosis?
No. BreathSense AI provides visual feature screening and preliminary risk indicators. All screening results should be reviewed by a certified healthcare professional or radiologist.
How is patient data secured?
All user data, logs, and profile records are encrypted and managed using Supabase Row Level Security (RLS) policies.
